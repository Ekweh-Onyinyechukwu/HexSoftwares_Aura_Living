## Case Study Overview
AuraLiving is a smart home dashboard concept designed for my HexSoftwares Internship Task 3. The goal of this project was to create a seamless interface that allows users to monitor, control, and automate their smart home devices from a single dashboard.

## Problem Statement
Many smart home systems feel cluttered and difficult to navigate, especially when users need quick access to essential controls like lighting, security, temperature, and energy monitoring. Users often struggle with scattered information and poor accessibility.

## Solution
I solved this problem by designing a clean and intuitive dashboard experience that simplifies smart home management through:
- Clear visual hierarchy
- Quick-access device controls
- Real-time monitoring cards
- Energy usage insights
- Room-based navigation
- Smart automation shortcuts

The interface was designed to help users interact with their home system efficiently while maintaining a modern and minimal aesthetic.

## Key Features
- Smart lighting controls
- Security camera monitoring
- Temperature regulation
- Device activity tracking
- Energy consumption analytics
- Automation scheduling

## Design Process
- User flow planning
- Mid-fidelity wireframing
- Dashboard structuring
- UI consistency and spacing
- Color palette selection
- Component-based design system

## Tools Used
- Figma

## Design Style
AuraLiving uses a modern smart-home aesthetic with deep navy backgrounds, soft gradients, clean cards, and accent colors to highlight important actions and data.

## Outcome
This project improved my understanding of dashboard layouts, information hierarchy, smart device interactions, and designing scalable systems across connected platforms.
